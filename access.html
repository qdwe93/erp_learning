교재 다운로드

사용자가 SAP Learning Hub에서 확인한 결과, 이 사이트에 정리한 모든 교육과정의 교재를 다운로드할 수 있습니다. 과정 표에서는 교재 다운로드 가능로 표시했습니다.

다운로드한 교재의 보관·공유 범위는 조직의 SAP 계약과 내부 정책을 따릅니다.

실습 시스템 일반 이용 규칙

SAP Learning 헬프센터가 유효한 SAP Learning Hub 구독에 대해 안내한 일반 규칙입니다. 실제 적용 여부는 로그인 후 과정별로 확인합니다.

항목내용
이용 시간제한 없음 — 시스템 유효기간 안에서는 시간 제한이 없습니다 (기존 60시간 제한은 폐지)
등록 방식학습자별 등록. 종료일이 고정돼 있고 연장할 수 없습니다. 만료 후 다시 등록할 수 있습니다
동시 등록학습자당 최대 2개까지 활성 상태로 둘 수 있습니다
준비 시간등록 후 즉시 열리는 시스템도 있고 최대 90분이 걸리는 것도 있습니다
