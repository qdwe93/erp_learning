공식 과정의 범위와 별도 기술 학습이 필요한 구간을 구분했습니다.

Fiori 외 프론트엔드를 연결하는 경우 SAP 공식 과정은 Fiori Elements와 SAPUI5를 중심으로 다룹니다. RAP로 OData 서비스를 노출하는 데까지를 먼저 학습하고, 이후 화면 구현은 선택한 프론트엔드 기술의 교육자료를 별도로 확인합니다.

커스텀 코드 판정 도구

S4D426 Unit 1에 가이드 시뮬레이션으로 들어 있습니다. 실제로 사용하는 커스텀 코드를 식별하고 범위를 정하는 방법을 다룹니다.

  • ABAP Call Monitor(SCMON)로 사용량 수집 — 실제 호출되는 리포트만 남깁니다
  • Custom Code Migration 앱으로 전환 범위 지정
  • ATC check variant ABAP_CLOUD_DEVELOPMENT_DEFAULT / ABAP_CLOUD_READINESS — Unit 5에 설명만 있고 직접 실행해 보는 부분은 없습니다

Fiori Elements 연계

S4D437 안에 annotation 기반 Fiori Elements 리스트·오브젝트 페이지를 직접 만들어 보는 단원이 있어 별도 과정이 필요 없습니다. Fiori 운영·관리가 필요하면 아래를 봅니다.
