커스텀 코드 학습

System Conversion 과정은 커스텀 코드 판정과 Clean Core 원칙을 함께 이해해야 합니다. 관련 도구와 학습경로는 별도 페이지에 정리했습니다.

ABAP · RAP 학습ABAP + CDS + RAP 학습경로와 커스텀 코드 판정 도구

Clean Core 판정

Practicing Clean Core Extensibility for SAP S/4HANA Cloud S4D426 (480분, 한국어)의 Unit 1이 커스텀 코드 검토를 다룹니다.

  • 사용량 데이터 수집 (ABAP Call Monitor)
  • 레거시 수정 · 복사 · 확장 검토
  • Custom Code Migration 앱으로 전환 범위 지정
  • 시스템 전환과 신규 구축 비교

Unit 5는 Private Edition 시스템의 개발 환경 설정을 다룹니다 — 소프트웨어 컴포넌트, 개발자 권한, ABAP 언어 버전 배정.

관련 Certification

Catalog에서 확인된 SAP S/4HANA Conversion 및 System Upgrade Certification입니다. 이 페이지의 자료 완료만으로 시험 준비가 끝나는 것은 아닙니다.
