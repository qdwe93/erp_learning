# 필요한 이미지 목록

사이트 이미지는 교육 탐색을 돕는 용도로만 쓴다. 회사·프로젝트 현황, 대상 릴리스, 물량, 내부 시스템 구성은 이미지에도 넣지 않는다.

생성 원칙은 `../../design.md` §7을 따른다. 요약하면:

- 사진이 아니라 **일러스트 / 다이어그램**. 사내 업무 포털이고 여행·마케팅 사이트가 아니다.
- **사람 사진·인물 일러스트를 넣지 않는다.** 특정 인물처럼 보이면 안 된다.
- **SAP 로고, SK 로고, 행복날개를 생성하지 않는다.** 실제 로고가 필요하면 공식 파일을 받아서 쓴다.
- 색은 SK CI 팔레트 안에서만 쓴다 (`design.md` §2).
- 파일당 **200KB 이하**, `.webp` 우선.

---

## 1. hero 일러스트 (필수)

| 항목 | 값 |
|---|---|
| 경로 | `assets/img/hero.webp` |
| 크기 | 1200 × 900 (4:3) |
| 쓰이는 곳 | `index.html` 히어로 우측 |

**내용**: 운영자가 모듈 타일에서 SAP 공식 과정과 실습 자료로 이동하는 학습 탐색 흐름. 모듈·과정·실습을 나타내는 추상 카드와 연결선으로 구성한다.

**색**: SK Navy `#0E306D`, SK Blue `#0072C6`, SK Teal `#009A93`를 중심으로 하고 강조 1점만 SK Orange `#F47725`를 쓴다.

**주의**: 이미지에 숫자·문자·로고·사람·프로젝트 타임라인·이전/목표 시스템을 넣지 마라.

**적용 방법**: `index.html`의 `<div class="hero-figure">` 안에 아래를 넣는다.

```html
<img src="assets/img/hero.webp" alt="SAP 공식 학습 자료가 모듈, 과정, 실습으로 연결되는 구조를 나타낸 일러스트" width="1200" height="900">
```

`build.mjs`의 `buildIndex()` 안 `IMAGE SLOT: hero` 주석 위치에 넣고 다시 생성하는 편이 낫다. HTML을 직접 고치면 다음 생성 때 지워진다.

## 2. ABAP · RAP 학습 범위 도식 (HTML로 구현)

| 항목 | 값 |
|---|---|
| 구현 | `custom-reports.html`에 생성되는 반응형 HTML 도식 |
| 쓰이는 곳 | &ldquo;SAP 공식 과정이 다루는 범위&rdquo; 절 |

**내용**: 좌 → 우 학습 범위.

```
CDS 데이터 모델 → RAP 비즈니스 오브젝트 → OData 서비스 노출 → Fiori Elements / 기타 Web 프론트엔드
```

**핵심**: 앞의 세 단계와 Fiori Elements는 **SAP 공식 과정에서 다루는 범위**, 기타 Web 프론트엔드는 **선택한 기술에 맞는 별도 학습 범위**로 구분한다. 특정 회사의 주 사용 기술이나 적용 비율은 쓰지 않는다.

표를 지우지 말고 접근 가능한 HTML 도식을 표 위에 추가한다. 이미지 파일은 만들지 않는다.

## 3. 모듈 아이콘 (선택)

| 항목 | 값 |
|---|---|
| 경로 | `assets/img/mod/{code}.svg` (예: `mm.svg`, `sd.svg`) |
| 크기 | 24 × 24 SVG, `stroke` 기반 |
| 쓰이는 곳 | `index.html` 모듈 카드, 모듈 페이지 상단 |

현재는 모듈 코드 글자(`MM`, `SD`)를 아이콘 자리에 넣고 있고 **그대로도 잘 읽힌다.** 아이콘이 오히려 코드보다 인지가 느릴 수 있으므로 우선순위가 낮다.

만든다면 13개 전부 같은 선 굵기(1.5px)·같은 여백으로 통일한다. 일부만 만들면 안 만드느니만 못하다.

필요 코드: `mm sd pp pm fi fi-aa co ewm tm hr tr group-reporting`

| 항목 | 값 |
|---|---|
| 경로 | `assets/img/og.png` |
| 크기 | 1200 × 630 |

사내 공유 시 미리보기용. 제목 텍스트 + SK 컬러 배경. 현재 `<meta property="og:image">`는 넣지 않았으므로 이미지를 만들면 `build.mjs`의 `layout()` head에 함께 추가한다.

## 만들지 말아야 할 것

- **스크린샷.** SAP 화면을 캡처해 넣으면 저작권과 현행성 문제가 동시에 생긴다.
- **사람 얼굴.** 참조로 준 두 사이트에는 인물 사진이 있지만 이 포털에는 넣지 않는다.
- **가짜 로고.** SAP·SK 로고를 생성해서 넣지 않는다.
- **장식용 blob·손그림 화살표.** 참조 사이트에 있지만 업무 포털에는 맞지 않는다고 `design.md`에서 명시적으로 뺐다.
